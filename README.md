# 汉字钥匙 — Ключи китайских иероглифов по фото

Веб-приложение для изучающих китайский язык: фото ключа (радикала) или
иероглифа → картинка, пиньинь (транскрипция), перевод на русский,
дополнительная информация (число черт, анимация порядка черт, примеры
слов, частотность/уровень HSK — если есть в базе).

## Возможности

- Загрузка фото (или съёмка с камеры телефона в браузере) одного ключа/иероглифа.
- Распознавание через Tesseract OCR (`chi_sim`).
- База всех **214 ключей Канси**: иероглиф, варианты написания, пиньинь
  (с тоновыми знаками), перевод на русский, число черт; для части ключей —
  примеры слов и уровень HSK.
- Плюс база из **~76 частых составных иероглифов** (не ключей) — тоже с
  полной карточкой (пиньинь, перевод, число черт).
- Анимация порядка черт (бишунь, 笔顺) через библиотеку [Hanzi Writer](https://hanziwriter.org/)
  (подгружается из CDN, нужен интернет в браузере). Число черт для
  символов вне обеих баз тоже подтягивается из тех же данных Hanzi Writer —
  прямо в браузере, для практически любого иероглифа.
- Если распознанный символ — не ключ и не из базы частых иероглифов,
  приложение всё равно покажет его пиньинь и английский перевод из
  локального офлайн-словаря на базе **CC-CEDICT** (~10 800 иероглифов,
  `data/cedict_chars.json`, работает без интернета). По желанию (галочка на
  странице загрузки, по умолчанию выключена) можно дополнительно перевести
  на русский через внешний сервис — переводится английский глосс из
  CC-CEDICT, а не сам иероглиф: так надёжнее, чем переводить одиночный
  символ без контекста напрямую.
- Страница "Все 214 ключей" с поиском по иероглифу/пиньиню/переводу.
- Если OCR ошибся — под результатом показываются другие варианты
  распознавания, по каждому можно посмотреть его карточку.

## Установка

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

### Tesseract OCR

Нужен установленный движок Tesseract с языковым пакетом `chi_sim`.

- Движок (Windows): `winget install UB-Mannheim.TesseractOCR`
- Языковые данные: в этом репозитории уже лежит `tessdata/chi_sim.traineddata`
  (скачан с [tesseract-ocr/tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast)),
  приложение подхватывает его автоматически — ничего доустанавливать не нужно.
- Если Tesseract стоит не по стандартному пути, укажи путь к `tesseract.exe`
  через переменную окружения `TESSERACT_CMD`.
- Если хочешь использовать свою системную папку `tessdata` (например, с
  более точной моделью `tessdata_best`), задай `TESSDATA_PREFIX` — тогда
  локальная папка `tessdata/` в проекте игнорируется.

## Запуск

```bash
.venv\Scripts\python main.py
```

Открой http://127.0.0.1:5000

По умолчанию `main.py` запускает продакшн-сервер [waitress](https://github.com/Pylons/waitress)
(без автоперезагрузки и отладчика — так безопаснее держать приложение
доступным извне). Для разработки, с автоперезагрузкой и отладчиком Flask,
задай `FLASK_DEBUG=1`:

```bash
set FLASK_DEBUG=1
.venv\Scripts\python main.py
```

Порт можно переопределить переменной `PORT` (по умолчанию 5000). Ключ
`FLASK_SECRET_KEY` (нужен только для подписи flash-сообщений, без
авторизации) можно задать вручную, иначе генерируется случайный при
каждом запуске.

## Структура проекта

```
app.py              — маршруты Flask
main.py             — точка входа (запускает app.py)
ocr/recognize.py     — препроцессинг фото + Tesseract OCR + пиньинь/перевод
ocr/radicals_db.py   — загрузка и поиск по базе 214 ключей
ocr/cedict.py         — загрузка офлайн-словаря CC-CEDICT (data/cedict_chars.json)
data/radicals.json   — база 214 ключей (можно редактировать вручную)
data/common_chars.json — база ~76 частых составных иероглифов
data/cedict_chars.json — офлайн-словарь CC-CEDICT для ~10 800 иероглифов вне этих двух баз
data/CEDICT_LICENSE.md — атрибуция и лицензия CC-CEDICT (CC BY-SA 4.0)
scripts/build_cedict.py — пересборка cedict_chars.json из сырого CC-CEDICT
templates/            — HTML-шаблоны (Jinja2, включая error.html для 404/413/500)
static/               — CSS и JS
tessdata/              — языковой пакет chi_sim для Tesseract
```

## Известные ограничения

- OCR одиночного символа с фото — не идеальный: качество сильно зависит от
  освещения, ровности кадрирования и почерка/шрифта, и может ошибаться даже
  на чистом, напечатанном символе. Кандидаты ранжируются по уверенности
  Tesseract (берётся лучшая по всем режимам PSM), что немного повышает шанс
  увидеть верный вариант первым, но не решает проблему полностью. Для этого
  в интерфейсе есть список альтернативных вариантов распознавания и ручной
  поиск по всем 214 ключам (в том числе прямо со страницы неудачного
  распознавания).
- Английский глосс из CC-CEDICT — офлайн и не зависит от сети, но это
  словарная статья, а не готовый перевод для новичка: иногда содержит
  несколько значений через точку с запятой, а для иероглифов, у которых
  разные традиционные написания слились в один упрощённый (например 游 —
  и от 游, и от 遊), выбранное значение может быть не тем, что ожидаешь.
- Онлайн-перевод через `deep-translator` (сначала MyMemory, затем Google
  как запасной вариант, каждый — с таймаутом 6 секунд, чтобы не подвешивать
  страницу) — best-effort, может не сработать при отсутствии интернета или
  ограничениях сервиса; тогда остаётся английский глосс CC-CEDICT без
  перевода. Переводится английский глосс, а не сам иероглиф (заметно
  надёжнее — см. выше), заведомый мусор (пустой ответ, эхо непереведённого
  текста, знак препинания) отбрасывается, регистр нормализуется под стиль
  остальной базы — но смысловая точность всё равно ниже, чем у вручную
  выверенных 214 ключей и ~76 частых иероглифов, и это не всегда
  фиксируется автоматически. По умолчанию галочка онлайн-перевода выключена
  (символ/глосс никуда не отправляется, пока пользователь сам её не включит).
- Анимация порядка черт (Hanzi Writer) тянет данные из CDN в браузере —
  без интернета вместо анимации будет пустой квадрат.
